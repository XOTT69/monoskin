# Як додати скін

1. Покладіть зображення у папку `public/skin/` (наприклад, `public/skin/kyiv.png`).
2. Скопіюйте будь-який блок у `data/skins.json` та заповніть поля.
3. Вкажіть у полі `image` шлях `skin/kyiv.png`. У `method` використовуйте: `Безкоштовний`, `За дію`, `Донат на банку` або `Підписка Base`.
4. У `status` вкажіть `Доступний` або `Недоступний`.
5. Зробіть commit і push у `main`. Сайт оновиться автоматично.

`id` має бути унікальним коротким ключем. `sourceUrl` — посилання для отримання скіна або довідки.
