# Як додати скін

1. Покладіть зображення у папку `public/skin/` (наприклад, `public/skin/kyiv.png`).
2. Скопіюйте будь-який блок у `data/skins.json` та заповніть поля.
3. Вкажіть у полі `image` шлях `skin/kyiv.png`. У `method` використовуйте: `Безкоштовний`, `Доступні всім`, `Донат на банку` або `Підписка Base`. Для скіна, який банк видає автоматично без посилання, використовуйте `Доступні всім`; якщо він уже недоступний — вкажіть статус `Недоступний`.
4. У `status` вкажіть `Доступний` або `Недоступний`.
5. За можливості заповніть `lastVerifiedAt` у форматі `YYYY-MM-DD`, коли перевірили посилання й умову. Це поле необов'язкове, але допомагає відстежувати актуальність.
6. Зробіть commit і push у `main`. Сайт оновиться автоматично.

`id` має бути унікальним коротким ключем. `sourceUrl` — HTTPS-посилання для отримання скіна або довідки. Чернетки зберігаються окремо у `data/drafts.json` і не показуються на сайті.
