# Як додати скін

1. Покладіть зображення у папку `public/skins/` (наприклад, `public/skins/kyiv.webp`).
2. Скопіюйте будь-який блок у `data/skins.json` та заповніть поля.
3. Вкажіть у полі `image` шлях `skins/kyiv.webp`, а в `availability` один зі статусів: `Безкоштовний`, `За донат`, `Недоступний`.
4. Зробіть commit і push у `main`. Сайт оновиться автоматично.

`id` має бути унікальним числом. `sourceUrl` — посилання, яке оператор має надати клієнту або використати як довідку.
