# Чернетка: скіни з Telegram

Тут **52 записів**, яких не було в поточному каталозі з 70 скінів на момент звірки 4 серпня 2026 року. Дані взяті лише з відкритих дописів @monobankskins, @monoqrs та @monoskinsua.

Зображення з чужими водяними знаками сюди не завантажувалися. Для кожного запису в `missing-skins.json` є поле `imageFile` — поклади своє чисте зображення саме за цією назвою в папку `images/`.

Наприклад: для «ВДНГ × mono» треба додати файл `images/vdnh-mono.png`.

Підтримуються PNG, JPG і WebP. Якщо формат інший — просто онови розширення у полі `imageFile`. Не перейменовуй `id`, щоб я міг швидко імпортувати записи.

Перед публікацією я ще раз перевірю активність банок і посилань: у цьому файлі поле `status` навмисно має значення `Перевірити`, адже умови донатів та підписок з часом змінюються.

Пости без назви скіна в тексті не внесені: назву та умови для них неможливо коректно відновити без вгадування. Посилання на джерело кожного внесеного запису є у `referencePostUrl`.
